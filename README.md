# 新华小学招生程序

面向家长的招生展示与意向报名页面，涵盖：

- 历史沿革
- 校园风景
- 校园特色
- 校园文化
- 师资力量
- 课程体系
- AI 招生顾问（本地知识库即时问答）
- 报名意向表（数据保存在浏览器 localStorage）

## 使用方法

用浏览器直接打开 `index.html` 即可，无需安装 Node 或打包。

或在本目录启动简易本地服务（若已安装 Python）：

```bash
python -m http.server 8080
```

然后访问 http://localhost:8080

## 说明

页面中的招生电话、地址、年龄政策等为演示示例，正式上线前请替换为学校真实信息。
